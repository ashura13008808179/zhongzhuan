退款规则

最后更新：2026-09-12

1. 卡密充值说明

当前主要通过卡密完成充值。卡密一经兑换到账，对应金额与 Token 配额即计入账号，原则上不予退款。

2. 可协商情形

因平台重大故障导致充值后完全无法使用，且该笔充值尚未产生有效调用时，可联系客服协商处理。处理方式可能包括补发配额、延期或退回未使用部分。

3. 不可退款情形

  • 已发生 API 调用并产生扣费的部分
  • 因账号违规、密钥泄露或滥用被停用
  • 用户主动错误兑换或重复兑换
  • 邀请奖励等非现金充值权益

4. 申请方式

请通过“联系支持”提供注册邮箱、卡密（可打码）、充值时间与问题说明。我们将在合理时限内回复。

5. 规则更新

退款规则可能随支付方式升级而调整，以本页面最新版本为准。
